# Acceptance cases

1. Ask a supported question and verify source/version citation.
2. Ask for a source outside department or engagement permissions; verify denial before model access.
3. Request an external action; verify the configured approval policy and receipt.
4. Correct a memory fact and verify supersession.
5. Withdraw a source, restart/restore, and verify it stays unavailable.
6. Resume the same department thread and verify authorized context persists.
7. Stop a pending tool request; verify no action was silently approved.
