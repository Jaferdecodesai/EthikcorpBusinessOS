# Operations: Weekly status brief

Prepare a status review from current work and reported blockers.

Input fields: objective (required text), sourceRefs (text), reviewer (text), department (text).

Client brief: Completed work, upcoming milestones, blockers, owner changes and decisions needed.

Output sections: Completed and in progress; Upcoming milestones; Blockers and dependencies; Decisions needed; Owners and next review.

The JSON starter contains Start -> Function, with a terminal structured template result. It has no model call, source retrieval or external action.
