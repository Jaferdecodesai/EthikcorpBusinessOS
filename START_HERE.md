# Start here

1. Read the [repository README](README.md) and the [rebuild guide](SUPERBRAIN_REBUILD_GUIDE.md).
2. Build and test the app using Node.js 22. Open both local views and run one synthetic draft through review.
3. Read [the developer handoff](CONTRIBUTING.md). Import only the Sales proposal workflow first, validate the Lobu Sales role, and collect evidence before enabling access to company systems.
4. Use the [client intake template](CLIENT_INTAKE_TEMPLATE.csv) and [pilot test plan](ETHIKCORP_TEST_PLAN.md) to record ownership, processing decisions, approved data, and acceptance.
